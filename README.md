# REN Portfolio

映像制作・MIXを行うクリエイターRENのポートフォリオサイト。

「あなたの活動のすぐそばに」をコンセプトに、
歌い手やクリエイターの活動をサポートするためのWebサイトとして制作しました。


## Overview

このサイトでは、RENが提供するサービスや制作実績、
依頼までの流れなどを紹介しています。

単に作品を掲載するだけではなく、
依頼者が安心して相談できることを目的として設計しました。

## Design Concept

### Theme

Modern × Creative


### Concept

「あなたの活動のすぐそばに」

依頼者の想いや活動に寄り添い、
作品制作を通して長く支えられる存在であることを表現するため、
シンプルでありながら温かみを感じられるデザインを目指しました。


### Design Philosophy

映像制作やMIXは、単に技術を提供するだけではなく、
制作者と依頼者が一緒に作品を作り上げていく活動だと考えています。

そのため、信頼感を与えるモダンなデザインをベースに、
手書きロゴや水彩表現による柔らかさを加え、
クリエイターらしい個性と親しみやすさを表現しました。


### Color

使用カラーは、落ち着きと信頼感を与える群青を中心に設計しています。

- Base
  - #0F172A
  - 安定感や信頼感を表現

- Main
  - #3F63C8
  - 創造性や専門性を表現

- Accent
  - #8AB4FF
  - 柔らかさや親しみやすさを表現

- White
  - #F8FAFC
  - 清潔感と余白を表現


### Logo Design

ロゴは自身の署名をベースに制作しました。

手書きによる温かみと、
制作者自身が責任を持って作品を届けるという意味を込めています。

また、ブランド表記である「REN」と、
署名として使用する「Ren」を使い分けることで、
ブランドとしての信頼感と個人クリエイターとしての距離感を両立しています。
